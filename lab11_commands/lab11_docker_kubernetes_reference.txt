============================================================ KUBERNETES
CONCEPTS ============================================================

Docker: Packages and runs containers.

Kubernetes: Manages containerized applications.

Cluster: Complete Kubernetes environment.

Node: Machine in the cluster.

Pod: Basic unit Kubernetes runs. Our Pod contains the FastAPI container.

Deployment: Maintains the desired number/version of Pods.

Service: Provides stable networking access to Pods.

Scaling: Changes the number of Pod replicas.

Recovery: Kubernetes recreates failed Pods to maintain desired state.
